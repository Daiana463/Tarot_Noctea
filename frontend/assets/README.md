# assets/

Esta carpeta está preparada para imágenes y recursos estáticos de NOCTEA.

## Qué colocar aquí

- `logo.svg` — Logo oficial NOCTEA (si se crea versión exportada)
- `favicon.ico` / `favicon.svg` — Favicon del sitio
- `og-image.jpg` — Imagen para Open Graph / redes sociales (1200×630 px)
- Fotografías propias de la consultora (sin imágenes de stock con derechos)

## Nota

El diseño actual usa ilustraciones CSS puras, por lo que el sitio funciona sin imágenes.
Para añadir imágenes reales, referenciarlas desde `index.html` o `styles.css` con rutas relativas.
